以下代码在 state 处于读保护期间尝试修改它，代码报错 `error[E0502]`，无法编译。

```rust
/* // ❌
let cur = state.read();
*state.write() = *cur + 1;
// */
```

### 使用 `*` 解引用

`read()` 后立即解引用，让 `cur` 不再持有 state 的借用

```rust
let cur = *state.read();
*state.write() = cur + 1;
```

### 把 Signal 当作函数调用

这种改法更简单，如下所示

```rust
let cur = state();
*state.write() = cur + 1;
```

### 克隆

使用 `clone()` 也可以解决这个问题

```rust
let cur = state.read().clone();
*state.write() = cur + 1;
```

### 使用代码块

如果读取的过程不只是复制一个简单值，而是需要执行一些操作，可以用一个独立的代码块

```rust
let cur = {
    let cur = state.read();
    // 执行其它操作
    *cur // 解引用后返回
};
*state.write() = cur + 1;
```

### 提前释放

或者使用 drop() 立即释放读保护

```rust
let cur = state.read();
let c = *cur;
drop(cur);
*state.write() = c + 1;
```

[关于 Drop 特征](../Rust/Drop%20特征.md)

### 使用语法糖

如果仅仅是为了基于 state 的当前值做点修改而不涉及其它操作，那最简单的写法就是使用信号的[语法糖](https://dioxuslabs.com/learn/0.7/essentials/basics/signals#ergonomic-methods-on-signals)。如下所示，一行搞定

```rust
state += 1;
```
