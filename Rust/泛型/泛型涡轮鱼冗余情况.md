先看结论：

- 在类型注解中使用涡轮鱼是冗余的，应该省略双冒号。
- 在表达式中需要指定泛型参数时，涡轮鱼才是必须的。

例如以下代码

```rust
struct MyContainer<T> {
    // Scene 3: 结构体字段类型注解中
    field: Vec::<T>,
}

// Scene 1: 出现在函数参数、返回值中
fn test_func(param: Option::<i32>) -> Result::<i32, &'static str> {
    // Scene 2: 出现在 let 语句的“类型注解”中
    let a: Vec::<i32> = Vec::new();

    // Scene 2: 出现在 let 语句的“右侧赋值”中 (标准涡轮鱼场景)
    let b = Vec::<i32>::new();

    // Scene 4: 其它情况 - 泛型 Trait 绑定/约束位置
    let c: &dyn AsRef::<str> = &"hello";

    // Scene 4: 其它情况 - 嵌套模式匹配 (Pattern Matching) 类型指定
    if let Some::<i32>(val) = param {
        return Ok::<i32, &str>(val);
    }

    Err::<i32, &str>("error")
}

fn main() {
    let _ = test_func(Some::<i32>(42));
    println!("全部通过编译！");
}
```

其中

- 结构体类型可以简写为 `field: Vec<T>`
- 表达式 `let b = Vec<i32>::new()` 是错误的，必须改用 `Vec::<i32>::new()`
- 表达式 `Err<i32, &str>("error")` 错误，必须改用 `Err::<i32, &str>("error")`。
- 或者改成 `Err("error")`，由于这种写法并没有指定泛型参数，不在本文的讨论范围内。
- Trait 约束位置 `let c: &dyn AsRef::<str>` 可以简写为 `let c: &dyn AsRef<str>`
