先安装 RustRover

```sh
brew install --cask rustrover
```

然后通过 RustRover 安装 Rust

![安装Rust](https://lib.zhaiduting.work.gd/uPic/RustRover%E5%AE%89%E8%A3%85Rust%E5%B7%A5%E5%85%B7%E9%93%BE.png)

如果今后想要升级 Rust 可以手动敲入以下命令

```sh
rustup update
rustc --version # 查看编译器版本
```

参考链接 https://www.jetbrains.com/help/rust/rust-toolchain.html#install-rust-from-ide

### 可能遇到的链接器错误

运行一个测试项目，发现 Windows 系统执行命令 `cargo run` 时报错如下

```sh
error: linker `link.exe` not found
```

原因：**Rust 默认依赖微软的 C++ 编译工具链（MSVC）来做最后一步的“链接”，但电脑上还没安装 VS C++ 构建工具，或者 Rust 安装了 MSVC 工具链却没有配套环境。**

可以通过如下命令安装相关依赖

```sh
choco install visualstudio2026-workload-vctools
```
